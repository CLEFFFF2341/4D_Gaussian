# 来源与核查边界

核查日期：2026-10-10。本轮是实验方案选型与实现入口核查，不是新增百篇论文阅读任务，也没有得到新算法实验分数。此前扩展阅读结论沿用项目已有报告；本轮仅为第一方向选择主干和协议。

## 本地保存范围

`source_audit/MoRGS/` 下保存了本轮下载成功的 `train.py`、`scene/utils.py`、`scene/dataset_readers.py`、`utils/loader_utils.py`。`source_audit/acquisition.json` 记录下载状态；部分直接下载因 SSL 连接错误失败，相关文件改用网页原文读取。**目录中的文件不是完整可运行仓库，不能据此启动训练。**

MoRGS commit 经远端引用核查后固定为 `5c62ae88b8fb2e3d4213329dd1ec3a61c66f8902`。网页读取成功不等于本地依赖安装成功；代码路径审阅不等于端到端 correctness 已证明。

## 必须留给执行阶段核实的内容

- CUDA 后端完整投影与像素网格语义，尤其源帧教师与当前几何的对应；目前是需要验证的风险，不是已确认的作者 bug。
- 当前 GPU 健康、MoRGS 本机编译、4090 峰值显存和完整流程耗时。
- README 评估命令与实际固定版本文件的一致性。
- 完整数据可下载性、各场景原始相机清单和 Meet Room 中央视角编号。
- 单独使用混合似然、目标可见性和两段联合归属是否有效；所有性能判断均等待实验。

搜索与代码证据支持“优先尝试这套方案”，不能支持“已证实它是所有基线中的全局最优”。本文档中的小规模门槛、默认 K/σ/ε、强对照和数据开发划分均是自行设计的实验约束，不冒充作者原设定。
