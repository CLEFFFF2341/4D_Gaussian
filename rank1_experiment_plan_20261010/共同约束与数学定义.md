# 共同约束与数学定义

本文件是所有阶段 prompt 的共同输入。以下是本方案提出的待检验结构与实现约定，不是声称已经由论文证明有效。相关证据和仓库选择见同目录《开始阅读_实验方案.md》。

## A. 工作目录、状态与公平性

工作根目录建议 `E:\4D_Gaussian\rank1_experiments`；方案根目录为 `E:\4D_Gaussian\rank1_experiment_plan_20261010`。若 GPU 环境位于 WSL/Linux，源码和编译放在 Linux 原生文件系统，记录 Windows 与 Linux 路径映射；不要在未核查条件时安装驱动、重启设备或修改已有训练环境。

每阶段维护 `experiment_state.json`，包含：阶段、完成/失败/未执行、源码 SHA、补丁 SHA、数据 manifest SHA、教师 SHA、划分 SHA、已跑命令、实际产物路径、结果摘要、下一步、阻塞原因。只有对应日志和产物存在才能标记完成。

每次运行保存 `resolved_config.json`、`command.txt`、`environment.json`、`metrics_per_frame.csv`、`resource.json`、日志和 checkpoint 索引。记录真实有效参数，不能只保存未生效的 YAML。

对照与本方法必须共享：训练/验证/测试视角，帧号和分辨率，光流教师及缓存，初始化（同种子），采样顺序，RGB/其他正则，运动参数化，投影模型，密度控制规则及点数预算，光流有效像素，停止规则。相同种子不保证 CUDA 完全确定，需报告实际重跑波动。

本方法不额外引入深度模型、大型视频网络或学习型 gate。先做损失替换，后续模块必须有独立对照。不要直接把本方案的计划文件名当作已有脚本：执行阶段应实现和验证入口后，再交付实际命令。

## B. 观测、像素网格与候选

令 a 为源帧，b 为目标帧。教师前向光流 `g_ab(p)` 定义在源像素 p，终点是 `p+g_ab(p)`，单位是当前评估分辨率的像素。

初版每个高斯的候选流使用中心投影差：

\[
f_i^{ab}=\pi_b(\mu_i^b)-\pi_a(\mu_i^a).
\]

其中 μ 必须是实际用于 RGB 渲染的几何位置，π 包含对应相机内外参。固定相机场景也保留完整投影，不直接用世界坐标 z 替代相机深度。中心位移不能描述高斯内部的旋转/形变流，作为已知近似记录；以后若使用 GaussianFlow 风格的局部仿射流，所有均值与混合对照必须同时替换。

**源帧 rasterization 的像素 p 才能对应 g_ab(p)。** 在当前帧像素网格上渲染一个位移再直接监督源帧光流，通常不具有这个对应关系；先用可知真值的平移例子核对实际后端是否做了补偿。不能只看 Python 变量名判错。

对于源帧像素 p，按原深度顺序计算所有贡献者的 `w_i=alpha_i*T_i`。T 必须包含此前所有贡献者，不是只包含选出的 K 个。辅助流头取权重最大的 K 个有效贡献者，初始 K=8；RGB 仍使用原完整合成流程。ID 选择和 w 停止梯度。

定义 `s = sqrt(W²+H²)/1024`，`y=g/s`，`m_i=f_i/s`。这使 σ 在不同分辨率间有一致的参考像素尺度。不得既归一化光流又再次按图像宽度缩放 σ。

初版在线训练冻结源帧状态，只向目标帧真实位置及其原有参数链回传流损失；均值与混合使用相同梯度边界。不得绕过 motion confidence/offset 仅更新一个不影响 RGB 的新 flow 变量。

### ID、密度变化和截断

数组下标不是高斯身份。使用持久 UID；克隆、分裂的新高斯获得新 UID，并记录 parent UID，不能把两个子高斯同时当作同一个物理轨迹。新生点没有过去对应时只参加 RGB；被剪枝点不再提供目标候选。先实现存活 UID 的一对一对应，不默认“相同祖先等于同一轨迹”。

流头在两帧都有有效身份的源贡献者上构造分布；无匹配候选时记为 abstain，保留该像素计数并记录原因。所有对照使用相同规则。持续报告三项覆盖率：匹配 UID 保留的源贡献质量、top-K 保留质量、实际有候选的有效像素比例。**不许静默删除困难像素后只报剩余像素的流损失。**

阶段 04/05 的第一组机制实验可以共同冻结帧间密度变化，以排除身份问题；恢复主干密度控制后必须重新比较，不能仅用冻结拓扑结果代替完整主干成绩。如果身份损失质量过大，停止扩大实验并修复映射，或明确限制方法适用范围。

## C. 初版概率模型

令选中的有效候选总权重为 S，`a_i=stopgrad(w_i/S)`。有效像素内 S>0；空集合单独按上述 abstain 处理。设 ε=0.02、σ=2 个参考像素，初版均为全局常数；使用宽异常分布 `p_out(y)=N(y;0,128²I)`，不学习每像素方差或 gate。

\[
P_{mix}(y\mid p) = \epsilon p_{out}(y)
+ (1-\epsilon)\sum_{i\in S_K(p)} a_i\,\mathcal N(y;m_i,\sigma^2 I).
\]

\[
\mathcal L_{mix}= -\frac{1}{|\Omega|}\sum_{p\in\Omega}\log P_{mix}(y(p)\mid p).
\]

Ω 来自教师前后向一致性、图像边界、有效数据和相机几何，不根据当前模型误差选择。空候选像素按固定异常分布记分，分母不因模型弃权减少；同时报告有梯度监督的覆盖率。概率密度可能大于 1，NLL 不必非负，不能因此截断为零。

FP32 计算 log Gaussian、log prior 和 logsumexp，禁止先 exp 求和再 log。高斯归一化常数不能省略后直接与异常分量相加。q 停止梯度不等于模型永远不能间接逃避监督：几何、opacity 和剪枝在下一轮仍会改变候选，必须用覆盖率和冻结候选消融检测。

后验责任度仅用于诊断和混合梯度：

\[
r_i=\frac{(1-\epsilon)a_i\mathcal N(y;m_i,\sigma^2I)}{P_{mix}(y\mid p)}.
\]

分量梯度与 `r_i(m_i-y)/σ²` 成比例。很远的全部候选可能被异常分量吞掉，导致梯度过小；对称假设也可能保留歧义。这是必须测量的失败模式，不能声称混合似然天然解决所有歧义。

## D. 必须存在的对照

| 代号 | 定义 | 用途 |
|---|---|---|
| B0 | 固定 commit 的原始 MoRGS，有来源支持的默认训练流程 | 报告作者实现参考；代码修复不得混入此标签 |
| B1 | 共享候选/投影/掩码的均值 `m_bar=Σa_i*m_i`，端点 Charbonnier 损失 | 检验均值聚合本身 |
| B2 | `-log[ε p_out(y)+(1-ε) N(y;m_bar,σ²I)]` | 排除收益仅来自稳健异常处理或概率损失 |
| H | `min_i[-log(a_i)-log N(y;m_i,σ²I)]`，硬 MAP 候选；异常项可作为额外候选且设置对齐 | 排除只要挑一个候选就够了 |
| M | 上节多分量混合 NLL | 最小方法 |
| B2V / MV | B2 / M 都使用完全相同的目标帧可见性权重 | 分离可见性与混合的贡献 |
| F0 | 真实计算路径关闭流损失 | 小规模辅助诊断，不作为唯一对手 |

B1/B2/M 中任何实现修正应同步；B0 与 B1 的差异须拆开说明。B2 是本方案设计的稳健均值对照，不是宣称精确复现某篇已有 SLAM 算法。

不同损失单位不同，不能仅以数值相同的 λ 称为公平。开发阶段在训练数据的固定 checkpoint 上校准流项与 RGB 项对共享运动参数的梯度范数比例。默认比例候选 `{0.03,0.1,0.3}`，σ 候选 `{1,2,4}`；采用顺序搜索，每个损失家族最多 6 组，允许对照用满相同预算。每个运行内 λ 固定；搜索只看开发验证视角，不看 cam00。正式冻结后不再按场景重新调参。

## E. 目标帧可见性：只做可检验的模块

先使用一个冻结的共享 B1 参考序列，提取目标帧各 UID 在教师终点 `u=p+g_ab(p)` 的真实 `alpha*T` 贡献，作为非负可见性分数 `v_i^b(u)`。它是渲染贡献代理，不是真实遮挡标签。目标位置采用教师终点，不采用每个候选自由移动的终点。

\[
\tilde a_i=\frac{a_i\,\mathrm{stopgrad}(v_i^b(u))}{\sum_j a_j\,\mathrm{stopgrad}(v_j^b(u))}.
\]

B2V 和 MV 使用同一个冻结参考、相同 UID 集和归一化。此“冻结参考”实验只在共同拓扑或可靠 UID 对应的设置下进行；不能拿独立训练后不对应的 UID 强行匹配。为了避免额外一遍训练成为隐含成本，正式候选应再测试同一模型内的滞后快照版本，每个 epoch 更新一次 gate、epoch 内固定，两种对照完全对称，并完整计时。

目标 top-K 中没有某 UID，不一定表示其不可见；需要全贡献查询或有误差界的候选集合并集。若所有分数为零，回退到源帧权重并记录 gate failure，不能让全部权重归零后用零损失奖励模型。教师判为真实遮挡的像素通常没有可靠光流标签，本方法不能凭这些无监督像素证明恢复了遮挡后的真实运动。

这里额外 gate、阈值、滞后更新均是可删减项。若 B2V 已解释全部收益，保留“可见性改善监督”的结果，放弃“混合归属带来独立收益”的主张。

## F. 可选升级：共享身份的轨迹联合似然

仅当 M/MV 有收益但仍存在跨帧归属跳变时执行。使用三帧 a,b,c 的两个相邻教师位移，沿第一段教师终点采样第二段。像素轨迹和前后向有效性由固定教师产生，不随当前模型变化。

令潜在 UID z 在两个观测段共享，`y_1,y_2` 为观测，`m_i1,m_i2` 为同一高斯的预测，使用同一锚点先验 A_i（必要时结合两端可见性后统一归一化）：

\[
P_J(y_1,y_2)=\epsilon\prod_{\ell=1}^2p_{out}(y_\ell)
+(1-\epsilon)\sum_i A_i\prod_{\ell=1}^2\mathcal N(y_\ell;m_{i\ell},\sigma^2I).
\]

损失为 `-log(P_J)/2`。对照 I 使用完全相同观测、候选、A_i、可见性和 σ，分别计算两段的混合 NLL 后取平均。J 和 I 的区别只在于是否在边缘化前共享潜在身份，不能增加一段观测后仅与单段模型比较。

在线版本只回看两帧，过去状态 detach，当前帧回传梯度；无需访问未来图像。不强制 `r_ab=r_bc`，不要求责任度熵越小越好。两段都有效但 UID 不能连通时记录覆盖损失；不伪造轨迹。独立分裂子点不是天然相同 UID，若证据不足就终止这一可选模块。

## G. 评估、证据强度和预注册门槛

主要指标：固定测试相机的 RGB PSNR、SSIM、LPIPS；明确 PSNR 是逐帧 PSNR 的平均而非先合并 MSE，按场景等权宏平均。统一 RGB 色域、值域、LPIPS 网络/版本与输入归一化。不同 LPIPS 实现产生的数字不混表。

补充指标：预先固定的动态区域、运动边界区域 PSNR/SSIM；这些区域可由测试图像上的冻结教师离线产生，但只在评估进程使用，绝不进入训练/调参。必须称为教师代理区域，不称为运动真值。区域边界宽度固定在参考分辨率，缩放同步。

真实运动机制使用合成真值流/轨迹和可见性验证；对训练教师的 EPE 下降只能说明拟合教师更好。不要用合成诊断冒充真实场景的 3D 轨迹正确性。

初筛门槛是本方案的工程止损规则，不是对收益的预测：

1. 单种子两场景筛选：相较验证集最强 B1/B2/H，至少一个场景整体 PSNR 上升，另一场景不明显退化；或者两个场景动态/边界区域均有改善且整体基本持平，才进入重复验证。
2. 三种子复核：优先要求平均整体 PSNR 提升约 0.10 dB，或边界区域提升约 0.30 dB 且整体退化不超过 0.05 dB；LPIPS 不系统恶化（默认绝对差 0.002 为提示线）。不能通过只挑一个指标绕过明显退化。
3. 若低于门槛但效应稳定且机制清楚，可标记“有限信号”，给出继续成本，不宣称已有效。两场景三种子不足以支持广泛统计结论。
4. 正式实验报告全部种子和场景；以场景为主要独立单位展示配对差值，种子作重复。不要把数百相邻帧当作数百独立样本制造显著性。
5. 同时报同迭代、相近总耗时及点数预算对照；主张更高效率必须计入教师、初始化和预处理。否则只能主张既定训练预算下的质量改善。

目标是得到可复现、可解释且经过强对照的研究结果。CVPR/ICML 级别取决于后续证据与贡献强度；若最终仅是现成稳健损失的轻微单场景收益，应如实降级，不用复杂包装补足证据。
